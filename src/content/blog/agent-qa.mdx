# agent-qa

[官网](https://vostride.com) · [GitHub](https://github.com/vostride/agent-qa) · [MCP 文档](https://vostride.com/docs/agent-qa/mcp)

agent-qa 让开发者与 AI Agent 通过 CLI、MCP 和 Skills 执行 Web、Android 和 iOS 测试并检查结果。持久记忆引擎保存经过验证的测试经验，自我改进能力帮助后续测试复用这些经验。

本地包免费，模型服务费用另计。需要 Node.js 24+ 和模型访问权限；移动端测试需配置相应的设备或模拟器。许可证为 FSL-1.1-ALv2。
